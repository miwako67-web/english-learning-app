【GitHubアップロード後の自動化ステップ】

### 1. 素材の準備（自動化に必要なファイル）
自動で毎朝動かすためには、今作ったプログラム（test_direct_send.py）に加えて、GitHubに「毎朝〇時に動かしてね」と指示を出すための設定ファイル（ワークフローファイル）が必要になります。

■ 追加するファイルの配置場所：
あなたのリポジトリ内に `.github/workflows/` というフォルダを作り、その中に `daily_news.yml` という名前でファイルを作成します。

---

### 2. 自動実行用ファイル（.github/workflows/daily_news.yml）
コード内に直接トークンが埋め込まれているため、GitHub Actionsの設定も非常にシンプルになります。

--------------------------------------------------
name: Daily AI News to Notion

on:
  schedule:
    # 毎日日本時間の朝7:00（世界標準時の22:00）に自動起動するタイマー設定
    - cron: '0 22 * * *'
  workflow_dispatch: # 手動でボタンを押して動かすこともできるようにする設定

jobs:
  run-script:
    runs-on: ubuntu-latest

    steps:
    - name: コードをチェックアウト
      uses: actions/checkout@v4

    - name: Pythonの環境セットアップ
      uses: actions/setup-python@v5
      with:
        python-version: '3.10'

    - name: 必要なライブラリのインストール
      run: |
        pip install google-genai notion-client

    - name: ニュース取得＆Notion送信プログラムの実行
      run: |
        python test_direct_send.py
--------------------------------------------------

---

### 3. 重要情報（今後の運用の流れ）
① `test_direct_send.py` と上記の `daily_news.yml` の2つのファイルをGitHubにアップロードします。
② これで、あなたのパソコンの電源が切れていても、GitHubのサーバーが毎朝自動でプログラムを立ち上げ、Geminiから最新ニュースを読み取ってNotionへ送信してくれるようになります。
